# Math Fight: Graph Arena

An interactive, graph-powered arithmetic arithmetic duel game built with Python using coordinates-based trajectories to target an automated CPU entity.

## System Prerequisites
* Python 3.8 or higher
* Pip package manager

## Installation

1. Clone the repository and navigate into the project root directory:
```bash
git clone https://github.com
cd math-fight-beta
```

2. Install the required external core libraries using the package installer:
```bash
pip install pygame numpy
```

## Running the Application

Execute the entry point module script to initialize the application framework and launch the game window loop:
```bash
python main.py
```

## Core Layout Controls
* **Movement Vectors:** Use W, A, S, D or Arrow keys to shift coordinates configuration.
* **Weapon Selection:** Use numerical keys 1 through 6 to alternate baseline presets.
* **Execution:** Press ENTER to process function calculations and fire curves.
* **Manual Entry:** Use standard keyboard inputs within Hard Mode configurations to pass direct custom string operations.
